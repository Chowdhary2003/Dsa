# DSA — Greedy Algorithm (Markdown)

This archive contains the Greedy Algorithm problem files in Markdown format.

## Contents

- 14 existing Markdown files, preserved byte-for-byte from the source archive.
- 4 C++ implementations converted into Markdown files with fenced `cpp` code blocks.
- 18 problem Markdown files in total.

## Notes

For the converted files, problem context is explicitly marked as inferred from the implementation because the standalone C++ source did not include the full original problem statement. The C++ implementation itself is retained in the Markdown code block.

See `conversion-manifest.json` for source-to-output mappings and SHA-256 hashes.
