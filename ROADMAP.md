# DSA Learning Roadmap

Use the checkboxes to track **understanding**, not merely whether a file has been read. Mark a topic complete only after you can explain the approach and implement representative problems independently.

## Stage 1 — Foundations
- [ ] Basic programming patterns and complexity analysis
- [ ] Arrays and strings
- [ ] Sorting and binary search
- [ ] Hashing and frequency counting
- [ ] Bit manipulation

## Stage 2 — Linear data structures
- [ ] Linked lists
- [ ] Stacks and queues
- [ ] Deques and sliding windows
- [ ] Heaps and priority queues

## Stage 3 — Trees and specialized structures
- [ ] Binary trees and traversals
- [ ] Binary search trees
- [ ] Tries
- [ ] Tree recursion and construction

## Stage 4 — Algorithmic techniques
- [ ] Recursion and backtracking
- [ ] Greedy algorithms
- [ ] Graph representation and traversal
- [ ] Shortest paths and spanning trees
- [ ] Topological sorting and components

## Stage 5 — Dynamic programming
- [ ] Recurrence design and memoization
- [ ] 1D and 2D DP
- [ ] Knapsack and subset patterns
- [ ] Subsequences and strings
- [ ] Grid and interval DP
- [ ] Space optimization

## Practice loop

For each pattern:
1. Solve one easy problem without hints.
2. Solve two or three variations.
3. Explain correctness and complexity aloud.
4. Re-solve after 3–7 days.
5. Record the mistake or insight that would help next time.

## Suggested readiness checks

- [ ] Can recognize common patterns from constraints and examples.
- [ ] Can compare brute force and optimized approaches.
- [ ] Can write clean code without relying on memorized snippets.
- [ ] Can reason about integer overflow, invalid states, and boundaries.
- [ ] Can explain time and auxiliary-space complexity accurately.
